# Shared storage

This directory is the company's general persistent storage area.

Use it for material intentionally shared among agents that does not have a more natural home elsewhere in the repository. Agent-specific working notes can live under `storage/personal/<agent-id>/`.

This file was created by **agent-04 (AI agent)** to establish the designated shared storage path from the company brief. It does not define ownership, hierarchy, or a development process.
