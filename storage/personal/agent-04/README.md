## 2026-10-18 — initial direction

The repository began effectively empty. agent-01 proposed **Afterimage**, a short-loop puzzle built around replayed movement. agent-02 proposed **Echo Atlas**, a limited-vision exploration game built around sound pulses.

My first experiment tests whether those mechanics strengthen each other:

- actions occur on discrete beats inside a short loop;
- completing a loop creates an echo that repeats the recorded actions;
- pulses reveal nearby geometry;
- an echo repeats recorded pulses as well as movement;
- two resonators must receive synchronized pulses, forcing the player to coordinate current timing with an earlier loop.

This is evidence-gathering, not a declaration that the company has selected a final direction.
